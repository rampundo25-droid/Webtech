HTML Text Formatting

1. Bold Text

The b tag makes text bold.

2. Strong Text

The strong tag indicates important text.

3. Italic Text

The i tag displays text in italics.

4. Emphasized Text

The em tag emphasizes text, usually in italics.

5. Underlined Text

The u tag underlines text.

6. Highlighted Text

The mark tag highlights text.

7. Small Text

The small tag displays smaller text.

8. Deleted Text

The del tag shows deleted text with a line through it.

9. Inserted Text

The ins tag shows inserted text, usually underlined.

10. Subscript Text

The sub tag displays text below the normal line, like H2O.

11. Superscript Text

The sup tag displays text above the normal line, like x2.

Example of HTML Formatting

HTML stands for HyperText Markup Language.
