HTML Text Formatting

1. Bold Text - <b>

The b tag displays text in bold.

2. Strong Text - <strong>

The strong tag indicates that text is important.

3. Italic Text - <i>

The i tag displays text in italics.

4. Emphasized Text - <em>

The em tag emphasizes text, usually in italics.

5. Underlined Text - <u>

The u tag underlines text.

6. Highlighted Text - <mark>

The mark tag highlights text.

7. Smaller Text - <small>

The small tag displays smaller text.

8. Deleted Text - <del>

My favorite color is red blue.

9. Inserted Text - <ins>

My favorite subject is Web Development.

10. Subscript Text - <sub>

Water is represented by H2O.

11. Superscript Text - <sup>

The equation is E = mc2.

Summary

HTML text formatting tags help us change the appearance and meaning of text on a webpage.
